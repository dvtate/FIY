FIY Server Admin Settings

This page is designed to provide an alternative to manually editing config files. Apparently that scares some people.

Restart FIY Server

In order to apply server settings changes, the server must be restarted.

WARNING:This will log out all users!

FIY Config

These settings are generally read from config.ini file. Note that if you start the FIY server with command overrides changing these settings may have no effect.

Mod Settings

Apps are internally referred to as "mods" or "modules." Here you can edit the settings for all installed mods. Normally this is done by editing module.json files.
